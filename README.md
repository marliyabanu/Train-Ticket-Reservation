# Train Ticket Reservation System

This project is a simple Train Ticket Reservation webpage created using HTML and CSS.

## Features
- Select From Station
- Select To Station
- Choose Travel Date
- Enter Passenger Details
- Select Class and Seats
- Mobile Number and Email Input
- Book Ticket and Clear Buttons

## Technologies Used
- HTML
- CSS

## Project Output
The webpage displays a train reservation form with a styled user interface.
